================================================================================
                        DEPLOYMENT PROCESS
================================================================================

Step 1: Build Frontend
  Command: npm run build
  Output: dist/ directory with optimized files

Step 2: Upload to Server
  Command: scp -r dist/ backend/ config files...
  Location: /var/www/crm-app/

Step 3: Install Dependencies
  Command: cd backend && npm install --production
  Database: SQLite auto-initialized

Step 4: Configure Nginx
  Copy nginx-crm.conf to /etc/nginx/sites-available/crm
  Reload nginx

Step 5: Set Up Backend Service
  Copy crm-backend.service to /etc/systemd/system/
  Enable and start service

Step 6: Verify
  Test API: curl http://127.0.0.1:5000/api/customers
  Test Frontend: http://165.232.54.109/crm
  Check logs
